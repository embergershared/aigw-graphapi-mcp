# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and keep discussions about the
work.

## Reporting

To report unacceptable behavior, use GitHub's **Report content** on the comment, issue or PR,
or [report the account to GitHub](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
The maintainer may edit or remove comments, and block accounts, that don't follow this code.
